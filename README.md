# HR Analytics Dashboard: Workforce, Attrition & Retention Analysis

## Project Overview
This project uses Power BI to analyze workforce composition, employee attrition, retention patterns, and employee experience. The goal is to identify workforce trends and provide insights that can support HR decision-making.

## Business Objectives
- Understand workforce demographics and composition.
- Analyze employee attrition patterns and potential risk factors.
- Explore retention patterns across tenure, compensation, and employee experience.
- Provide actionable recommendations to support employee retention.

## Dashboard Pages
1. **Workforce Overview** — workforce demographics, department distribution, job roles, and employee tenure.
2. **Attrition Analytics** — attrition patterns and their relationship with overtime, tenure, compensation, and demographics.
3. **Retention & Employee Experience** — retention patterns across job satisfaction, work-life balance, compensation, and tenure.

## Tools
- Power BI
- Power Query
- DAX
- Data Visualization

## Key Deliverables
- Interactive Power BI dashboard
- Workforce and attrition analysis
- HR insights and recommendations

## Disclaimer
This project is for portfolio and analytical demonstration purposes. Any simulated dates or predictions should be interpreted as illustrative rather than actual historical events or validated predictive results.
